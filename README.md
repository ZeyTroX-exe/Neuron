# Simple Neural Network

A neural network project written in Go, starting with a basic artificial neuron and gradually expanding towards a more advanced machine learning implementation.

### Current Features
- **Artificial Neuron:** Implements weights, bias, and a configurable learning rate.
- **Prediction:** Calculates outputs using weighted inputs.
- **Training:** Adjusts weights and bias based on prediction errors.
- **Supervised Learning:** Learns from input-target pairs over multiple training epochs.

### Planned Development
- Multiple neurons and layers
- Activation functions (ReLU, Sigmoid, Tanh)
- Forward propagation
- Backpropagation
- Gradient descent
- Training datasets
- Model evaluation and testing
